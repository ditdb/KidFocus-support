# KidFocus（定心宝）支持页

[English](https://github.com/ditdb/KidFocus-support/blob/main/README.md) · [隐私政策](https://github.com/ditdb/KidFocus-support/blob/main/PRIVACY.md)

家长选出孩子上网课需要的 App，设好上课时间。时段内，iPad 上其余 App 会被屏蔽，下课后自动恢复。应用基于 Apple 的屏幕使用时间框架，没有账号，也不联网。

## 联系我们

问题、故障反馈或建议： <ditdb.team@gmail.com> 

请附上 iPad 型号、iPadOS 版本和 KidFocus 版本（设置 → 关于）。如果规则没有生效，请同时附上「设置 → 诊断 → 导出诊断信息」得到的文本，里面不含任何 App 名称和个人信息。

## 快速上手

1. 打开 KidFocus，允许「屏幕使用时间」权限。
2. 设置 6 位数字的家长密码，不要告诉孩子。
3. 点 **+** 新建规则：起名、选 App、设置开始和结束时间、选择重复的星期。
4. 打开「有效」。时间一到，其他 App 自动被屏蔽；时间结束后自动恢复。

为了更好的防护，建议：

- 孩子的 iPad 使用加入「家人共享」的儿童 Apple ID，并在授权时选择「儿童账号」。
- 在系统设置里设置「屏幕使用时间」密码。

## 常见问题

### 「仅允许所选 App」和「仅屏蔽所选 App」有什么区别？
- **仅允许所选 App**（默认）：时段内只有你选的 App 能用，其余全部屏蔽，适合上网课。
- **仅屏蔽所选 App**：时段内你选的 App 被屏蔽，其余照常使用，适合限制游戏、视频。

### 规则没有生效，该检查什么？
1. 设置里「屏幕使用时间授权」应显示「已授权」。授权被撤销时，规则列表顶部会出现红色横幅，点「重新授权」。
2. 确认规则「有效」已打开，并且当前时间和星期在时段内。
3. 进入「设置 → 诊断」，点「立即对账」。如果仍显示问题，请导出诊断信息发给我们。

### 为什么无法启用规则？
两条有效规则的时段不能重叠：请先停用其中一条，或修改时间、重复日。另外，必须先授权屏幕使用时间，才能启用规则。

### 忘记家长密码怎么办？
家长密码无法找回或重置。这是有意的设计：不需要任何凭证的重置，孩子也能用。要重新设置：

1. 在系统设置里撤销 KidFocus 的屏幕使用时间授权（儿童账号下可能需要监护人验证）。
2. 删除 KidFocus，再重新安装。

专注规则会一起被清除，需要重新创建。

### 为什么删不掉 KidFocus？
有规则启用期间，「防护增强」会禁止删除，避免孩子靠删除应用来绕过屏蔽。想卸载时，请在 KidFocus 设置里关闭「防止删除 KidFocus」，或停用所有规则。

### 为什么不能改日期和时间？
有规则启用期间，KidFocus 会要求自动设置日期与时间，防止孩子靠改系统时间绕过专注时段。你可以在 KidFocus 设置里关闭它（需要家长密码）。

### 孩子能绕过 KidFocus 吗？
如果孩子知道家长密码或「屏幕使用时间」密码，KidFocus 无法阻止。使用「本人账号」授权时，孩子也可以在系统设置里自行撤销授权，所以建议使用加入「家人共享」的儿童账号。

### 跨午夜的时段可以吗？
可以。例如 22:00 到次日 06:00，按开始那天计算。

### KidFocus 收集什么数据？
不收集任何数据，详见[隐私政策](https://github.com/ditdb/KidFocus-support/blob/main/PRIVACY.md)。
